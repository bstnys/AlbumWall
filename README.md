# AlbumWall

지금 듣고 있는 노래의 앨범 커버를 맥 바탕화면에 띄워 주는 앱이에요.

- 바탕화면 가운데에 앨범 커버 한 장이 떠요. 배경색은 커버 색에 맞춰 자동으로 바뀌어요.
- 마우스를 가까이 가져가면 커버가 커서 쪽으로 살짝 기울어요.
- 커버를 클릭하면 음악이 재생되거나 일시정지돼요.
- **Spotify**나 **음악 앱(Apple Music)**에서 곡이 바뀌면 커버도 블러 효과와 함께 바뀌어요.
- 아무것도 재생하지 않을 때는 직접 넣어 둔 커버 이미지를 보여 줘요.

다른 창이 덮고 있는 곳에서는 반응하지 않고, 바탕화면이 보이는 곳에서만 반응해요. 바탕화면 아이콘과 위젯도 그대로 쓸 수 있어요.

## 필요한 것

- macOS 13 Ventura 이상
- Apple Silicon 맥, 인텔 맥 모두 지원

## 설치

### 방법 1. 앱 다운로드 (추천)

1. [Releases](../../releases/latest)에서 `AlbumWall.zip`을 내려받아 압축을 풀어요.
2. `AlbumWall.app`을 **응용 프로그램** 폴더로 옮겨요.
3. 앱을 더블클릭해서 실행해요.
4. 처음 실행하면 "확인되지 않은 개발자" 경고가 떠요. 이 앱은 Apple 공증을 받지 않았기 때문이에요.
   - **시스템 설정 → 개인정보 보호 및 보안**으로 가요.
   - 아래쪽에 있는 **"그래도 열기"**를 누르고, 앱을 다시 실행해요.
   - 이 과정은 처음 한 번만 하면 돼요.

### 방법 2. 직접 빌드

Xcode 명령어 도구가 필요해요. 없으면 터미널에서 `xcode-select --install`로 설치해요.

```bash
git clone https://github.com/bstnys/AlbumWall.git
cd AlbumWall
./build.sh
cp -R AlbumWall.app /Applications/
open /Applications/AlbumWall.app
```

## 처음 설정

### 음악 앱 연결 권한

Spotify나 음악 앱에서 노래를 재생하면 이런 창이 떠요.

> "AlbumWall"이(가) "Spotify"을(를) 제어하려고 합니다.

**허용**을 눌러 주세요. 허용해야 커버를 가져오고, 클릭으로 재생과 일시정지를 할 수 있어요.

창이 뜨지 않았거나 실수로 거부했다면 **시스템 설정 → 개인정보 보호 및 보안 → 자동화**에서 AlbumWall 아래 항목을 켜면 돼요.

### 로그인할 때 자동 실행

**시스템 설정 → 일반 → 로그인 항목 및 확장 프로그램**에서 **"로그인 시 열기"** 아래 **+** 버튼을 눌러요. 그다음 응용 프로그램 폴더의 AlbumWall을 추가해요. 메뉴 막대의 💿 아이콘 메뉴에서도 켤 수 있어요.

## 사용법

### 기본 커버 넣기

음악을 재생하지 않을 때 보여 줄 커버를 넣을 수 있어요.

1. Finder에서 `⌘⇧G`를 누르고 `~/Pictures/AlbumWall`을 입력해요. 앱을 처음 실행할 때 자동으로 만들어지는 폴더예요.
2. 그 폴더에 앨범 커버 이미지(jpg, png, webp, heic 등)를 넣어요.
3. 바탕화면이 자동으로 새로고침돼요.

여러 장을 넣으면 이름순으로 첫 번째 이미지를 써요.

### 메뉴 막대

메뉴 막대의 💿 아이콘을 누르면 이런 메뉴가 있어요.

- 앨범 커버 폴더 열기
- 새로고침
- 로그인 시 자동 실행
- 종료

메뉴 막대에 아이콘이 많아서 💿 아이콘이 안 보이면, 터미널에서 이렇게 종료할 수 있어요.

```bash
pkill AlbumWall
```

## 알아 두면 좋은 것

- **멜론, 지니, YouTube Music 같은 다른 음악 앱은 지원하지 않아요.** 이런 앱은 외부 앱에 현재 곡 정보를 알려 주는 방법이 없어요.
- **음악 앱에서 Apple Music 스트리밍 곡은 커버가 안 나올 수 있어요.** 보관함에 추가한 곡은 대부분 잘 나와요. 커버를 가져오지 못하면 기본 커버를 대신 보여 줘요.
- Spotify와 음악 앱을 둘 다 켜 두면 실제로 재생 중인 쪽을 따라가요. 둘 다 재생 중이면 Spotify를 우선해요.
- 대기 중일 때 CPU는 1% 미만, 메모리는 약 100MB를 써요.

## 삭제

1. `pkill AlbumWall`로 앱을 종료해요.
2. 로그인 항목에 추가했다면 거기서 빼요.
3. 응용 프로그램 폴더에서 AlbumWall.app을 휴지통으로 옮겨요.
4. 필요하면 `~/Pictures/AlbumWall` 폴더도 지워요.

## 구조

| 파일 | 역할 |
|---|---|
| `main.swift` | 바탕화면 높이에 창을 띄우고, 마우스 입력 전달과 Spotify·음악 앱 연동을 맡아요. |
| `web/index.html` | 커버 표시, 기울기, 블러 전환, 배경색 추출을 맡아요. |
| `build.sh` | 유니버설 앱을 빌드해요. `--zip`을 붙이면 배포용 zip도 만들어요. |
